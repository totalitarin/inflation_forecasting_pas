# Результаты контрольного запуска ПР3

Контрольный запуск выполнен 26 ноября 2026 года на реальных данных, загруженных из Audit-it и XML Банка России. Снимок содержит 201 месячное наблюдение с января 2010 по сентябрь 2026 года. На момент выгрузки выбранная таблица ИПЦ содержала значения только по сентябрь 2026 включительно. Последний прогноз относится к октябрю 2026 и является историческим примером; его нельзя выдавать за актуальный прогноз на следующий месяц относительно даты запуска.

После формирования лагов осталось 189 обучающих строк с 11 признаками; последние 36 месяцев, октябрь 2023 — сентябрь 2026, последовательно проверялись с расширением обучающего окна. Каждый прогноз использовал заново обученную модель с внутренним подбором alpha.

## Ошибки прогноза

| Модель | MAE, п.п. | RMSE, п.п. | MASE |
|---|---:|---:|---:|
| linear | 0.2993 | 0.3991 | 0.6088 |
| ridge | 0.2744 | 0.3720 | 0.5586 |
| seasonal | 0.3261 | 0.4192 | 0.6637 |

Ridge на этом периоде имеет наименьшую MAE. Это наблюдение о конкретном бэктесте, а не обещание будущего превосходства. Выбор окончательной модели по этому тесту программой не выполняется: сохраняются прогнозы обеих регрессий.

## Проверка интервалов

На первые 12 проверочных месяцев интервалы не строились: прошлых ошибок было недостаточно. Покрытие рассчитано на оставшихся 24 месяцах. Для обеих регрессий фактическое покрытие 95% интервала составило 87,5%, что ниже номинального значения. Для 80% интервала покрытие составило 62,5% у линейной регрессии и 70,8% у Ridge. Следовательно, интервалы недостаточно откалиброваны и требуют дальнейшей проверки, особенно на структурных сдвигах. Они представлены как эмпирическая оценка неопределённости без гарантии покрытия.

## Проверки программы

Шесть автоматических проверок подтверждают обработку ошибочной истории, отсутствие будущих значений в признаках, правильный месяц следующего прогноза, перевод индекса ИПЦ в процентный прирост, неизменность предыдущих прогнозов и интервалов при изменении последнего факта, а также минимальное число ошибок для построения интервалов.

Синтетические данные используются только в тестах. Метрики выше рассчитаны на зафиксированной реальной истории. Ретроспективная оценка не учитывает исторические пересмотры и даты фактического выхода публикаций.

## Воспроизведение

```bash
python -m pip install -r requirements.txt
python main.py --input data/reference/monthly.csv
```

Результаты появляются в `reports/generated/pr3/`: `index.html`, три графика HTML, `monthly.csv`, `features.csv`, `backtest.csv`, `metrics.csv`, `coefficients.csv` и `forecast.json`. Пакеты зафиксированы в `requirements.txt`. Сохранённые контрольные численные результаты находятся в `docs/results/`.
