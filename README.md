# Прогноз месячной инфляции в Российской Федерации

Учебный проект по дисциплине «Проектирование аналитических систем». Реализована ПР3: обработка данных, обычная линейная регрессия и Ridge с лагами, временной бэктест и интерактивные графики. Горизонт — один месяц. GUI на Streamlit планируется в ПР4.

## Быстрый запуск

Python 3.11+; команды выполняются из корня проекта:

```bash
python -m pip install -r requirements.txt
python main.py --input data/reference/monthly.csv
```

Откройте `reports/generated/pr3/index.html`: история и прогноз, сравнение метрик, коэффициенты. Рядом сохраняются CSV и JSON. Графики работают без интернета.

Обновление из сети:

```bash
python main.py --download --start-year 2010 --end-year 2026
```

Источники: месячный ИПЦ из вторичной публикации данных Росстата на Audit-it; официальный USD/RUB Банка России через XML. Возможен свой CSV `date,cpi_mom[,usd_rub_mom]`. `cpi_mom=0.8` означает прирост 0,8%, а не индекс 100,8.

## Методика

- Лаги ИПЦ 1, 2, 3, 12, скользящие средние 3 и 12, лаги изменения курса и сезонные признаки.
- LinearRegression и Ridge; alpha подбирается на внутренней временной валидации.
- Последние 36 месяцев — расширяющееся внешнее окно, прогноз на один месяц на каждом шаге.
- MAE, RMSE и MASE; сезонный наивный прогноз для сравнения. MAPE не используется.
- Эмпирические 80% и 95% интервалы по прошлым ошибкам; фактическое покрытие проверяется отдельно.

Архив публикаций и пересмотров не восстановлен: бэктест использует актуальный снимок истории. Из внешних факторов реализован USD/RUB; остальные остаются планом развития. Автоматическая загрузка выполняется целиком и журналируется, инкрементальное версионированное хранилище пока не реализовано.
